# 811lab.cn

811lab.cn 是个人成长博客与工作室档案，记录正在进行的学习、项目、研究路线、书架和小工具。

## 目录结构

```text
.
├── index.html      # 首页：记录、工作室档案、书架与研究路线
├── style.css       # 首页样式
├── main.js         # 首页导航、筛选和书架检索
├── roll/
│   ├── index.html  # 课堂抽签，访问地址为 /roll/
│   ├── classes.js  # 班级与抽签逻辑
│   └── images/     # 抽签所需的班级照片
└── PayingForKnowledge/  # 其他项目，暂未接入首页
```

吃饭转盘已移除。课堂抽签保留为低调入口，不参与首页主内容展示。

## 本地预览

```powershell
npx --yes http-server . -p 4173 -c-1
```

然后打开 http://127.0.0.1:4173/。

## 内容来源

首页中的工作室档案和书架目录基于本地 `D:\Obsidian\工作室` 整理。原始目录只读，不属于本仓库的运行时依赖；硬件清单和项目总览中的空白内容会在形成真实记录后继续补充。
