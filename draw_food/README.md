# 今天吃什么 - 抽签转盘

一个纯前端小工具：在一个转盘上随机抽取要吃的食物。

- 内置备选项：`options.txt`
- 本地缓存：所有增删会保存到浏览器 LocalStorage
- 支持导入/导出 TXT（每行一个备选项）
- 支持抽中后自动移除
- 动画时长可调

## 运行

由于浏览器安全策略，如果直接双击 `index.html` 打开，可能无法读取 `options.txt`。建议使用本地静态服务器：

- 如果已安装 Python：

```bash
python -m http.server 5173
```

打开浏览器访问 `http://localhost:5173/`。

- 或者使用 Node：

```bash
npx --yes serve -l 5173 .
```

## 使用

- “添加”可加入自定义选项；“打乱”随机重排。
- “选中后从列表移除”勾选时，抽到的选项会被删除。
- “导入TXT” 选择本地 `.txt`（每行一个词）；“导出TXT”下载当前列表。
- “重置为内置列表”会使用 `options.txt`/内置默认数据覆盖当前列表。
